## Hero

**Building small, focused products across infrastructure, AI, K-12, PropTech, IIoT, media, games, and operator tooling.**

Gmacko LLC is the operating home for Graham Mackie's product experiments,
venture work, infrastructure, and AI-assisted engineering systems. The goal is
to turn specific market problems into real software, test them quickly, and
push the promising ones toward revenue.

---

## About

> _Build in public, ship with discipline, keep the feedback loop tight._

Gmacko is a venture studio rather than a single-product company. The portfolio
spans deployment infrastructure, on-prem AI, property tax appeals, school
operations, student-run sports broadcasting, Roblox-native learning, industrial
controls, habit games, and internal tools for operating the whole orbit.

The shared operating philosophy is simple: pick real problems, build working
systems, measure demand, and avoid confusing activity with progress. AI is part
of the workflow, but it is treated as leverage inside structured engineering
processes, not as a replacement for product judgment.

## Stack

Most products share a pragmatic TypeScript-first foundation, with exceptions
where the problem calls for another tool.

| Layer | Default | Notes |
| --- | --- | --- |
| **Web** | Next.js, React, Tailwind | Product dashboards, portals, admin tools |
| **Mobile** | Expo / React Native | Parent apps, control surfaces, consumer products |
| **API** | tRPC, Node.js | Go where performance or protocol work matters |
| **Data** | Neon Postgres, Drizzle, Turso | Product data, edge data, lightweight prototypes |
| **Auth** | Clerk, Better Auth | Product-specific choices by audience |
| **AI** | LLM workflows, RAG, agent tooling | Structured workflows over ad-hoc prompting |
| **Infra** | Cloudflare, Docker, Kubernetes, Gitea | Self-hosted services where useful |
